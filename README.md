## Deskripsi Singkat
Project ini adalah sebuah aplikasi kalkulator sederhana berbasis Python yang dikembangkan sebagai bagian dari tugas Workshop Git. Project ini fokus pada implementasi fungsi-fungsi matematika untuk menghitung luas berbagai bangun datar serta penerapan unit testing untuk memastikan keakuratan perhitungan.
